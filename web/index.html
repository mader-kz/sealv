Blurs each crop before inference. Measured on aerial wildlife footage: −70% false positives on ambiguous ground (wet sand, shingle) for −13% real detections. Sharpening does the opposite and is not offered — the spurious hits live in compression noise, not structure.

Decoding

Temporal consensus

The model gives no confidence score. This builds one: a hauled-out animal is found in frame after frame, a texture artefact flickers. Camera drift is registered out first (~57px between frames on real footage, so raw coordinates would never match).
