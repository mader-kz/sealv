The replay release: the count, shown as it was earned. The frame fills with
detections dot by dot while the tally climbs, and every georeferenced animal
lands on satellite imagery in the same instant — one clock, two views, fully
scrubbable.

Релиз реплея: подсчёт показан так, как он был получен. Кадр заполняется
детекциями точка за точкой, счётчик растёт, и каждое георазмеченное животное
в тот же миг ложится на спутниковый снимок — один таймер, два вида, с
перемоткой.

## What's Changed
### New Features
- Add a count replay to the sortie inspector: the counted frame on the left fills with the run's own detections while the tally ticks up, and each georeferenced animal drops onto a satellite map on the right in sync — with play, pause and a scrub strip
- Add `GET /v1/runs/{id}`: the job route's result block addressed by run id, plus the media and job ids a hydrated client needs to fetch a video run's reference frame

### Improvements
- Improve the sortie inspector's frame box: video sorties now carry a replay control, and photo sorties offer replay next to the evidence view

## Что изменилось
### Новые возможности
- Добавить реплей подсчёта в инспектор вылета: слева кадр заполняется детекциями самого расчёта под растущий счётчик, справа каждое георазмеченное животное синхронно ложится на спутниковую карту — с воспроизведением, паузой и перемоткой
- Добавить `GET /v1/runs/{id}`: блок result из маршрута задач, адресуемый по id расчёта, плюс id медиа и задачи, которые нужны клиенту после перезагрузки, чтобы получить опорный кадр видеорасчёта

### Улучшения
- Улучшить блок кадра в инспекторе вылета: у видеовылетов появилась кнопка реплея, у фотовылетов реплей доступен рядом с окном доказательства
