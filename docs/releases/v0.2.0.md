The platform release: the SEALv web platform and the counting engine are one
product now. What the map shows is what the engine counted.

Релиз платформы: веб-платформа SEALv и счётный движок теперь один продукт.
То, что показывает карта, — то, что посчитал движок.

## What's Changed
### New Features
- Add the SEALv web platform (frontend/) served at the root: MapLibre chart of the Caspian, sortie ingest, analytics, command palette
- Add the real counting pipeline behind ingest: upload, queue, live progress, per-animal detections and the low/best/high band on the map — replacing synthetic detections
- Add photo ingest with a map-pinned location, so a single aerial still can be counted end to end
- Add reload survival: on boot the platform restores the season's counts from the service, with flight tracks and a streaming video preview
- Add client-parsed GPS handover: embedded MP4 tracks and pinned paths upload as a JSON sidecar, enabling server-side georeferencing and altitude-driven tiling
- Add verdict persistence: validate / mark-false in the Workbench writes to the service's append-only edit log
- Add GET /v1/media/{id}/track for redrawing a sortie's flight path
- Add a Caspian map view to the operator webapp with an embedded offline coastline
- Add shadcn/ui components skinned onto the platform's design tokens

### Bug Fixes
- Fix the analytics tab never rendering: a local variable shadowed the i18n function and the exception emptied every panel
- Fix roughly 25 runtime strings that ignored the translation table, so Russian and Kazakh screens no longer show English
- Fix Russian plural forms («52 съёмки», not «52 съёмок») and translate raw API values like union_4_frames in every locale

### Improvements
- Improve the operator webapp responsive layout and touch targets
- Improve the Docker build with a Node stage that compiles the platform inside the image
- Improve the i18n checker to hard-fail on duplicate locale keys, where the last value silently wins

## Что изменилось
### Новые возможности
- Добавить веб-платформу SEALv (frontend/) на корне сервиса: карта Каспия на MapLibre, приём съёмок, аналитика, командная палитра
- Добавить реальный счётный конвейер за загрузкой: отправка, очередь, живой прогресс, детекции по каждому животному и диапазон low/best/high на карте — вместо синтетических детекций
- Добавить приём фото с точкой на карте, чтобы одиночный аэроснимок считался от начала до конца
- Добавить переживание перезагрузки: при старте платформа восстанавливает подсчёты сезона из сервиса, с треками полёта и потоковым видеопревью
- Добавить передачу распарсенного клиентом GPS: встроенные треки MP4 и проложенные вручную пути загружаются JSON-сайдкаром, включая серверную геопривязку и тайлинг по высоте
- Добавить сохранение вердиктов: validate / mark-false в Workbench пишутся в append-only журнал правок сервиса
- Добавить GET /v1/media/{id}/track для отрисовки маршрута полёта съёмки
- Добавить карту Каспия в операторский интерфейс со встроенной офлайн-береговой линией
- Добавить компоненты shadcn/ui, посаженные на дизайн-токены платформы

### Исправления
- Исправить вкладку аналитики, которая не отображалась никогда: локальная переменная затеняла функцию i18n, и исключение опустошало все панели
- Исправить около 25 строк интерфейса, игнорировавших таблицу переводов, — русский и казахский экраны больше не показывают английский
- Исправить русские формы множественного числа («52 съёмки», а не «52 съёмок») и перевести сырые значения API вроде union_4_frames во всех локалях

### Улучшения
- Улучшить адаптивную вёрстку и области касания операторского интерфейса
- Улучшить сборку Docker: Node-стадия собирает платформу внутри образа
- Улучшить проверку i18n: жёсткая ошибка на дубликатах ключей локали, где молча побеждает последнее значение
