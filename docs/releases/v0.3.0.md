The platform release: from a counter to a survey platform. Frame-first video,
field records, review at scale, honest analytics — in three languages.

Релиз платформы: из счётчика — в платформу учёта. Видео через выбор кадра,
полевые записи, проверка в масштабе, честная аналитика — на трёх языках.

## What's Changed
### New Features
- Add a frame picker for video: choose the best frame in a large lightbox and count it as a single image, with an honest basis label and a movement warning when the clip flew a strip
- Add field notes, manual ground counts, site naming, metadata correction and survey retirement with undo — every entry attributed and kept in the edit log
- Add a review workflow that scales: keyboard verdicts walk the weakest detections first, and a pass survives Escape and reload
- Add per-animal GeoJSON/CSV exports and a survey report PDF that renders Kazakh and Cyrillic text
- Add site dynamics over repeat visits and a data-trust panel: verified share, scale provenance, engine caveats and determinism
- Add a trilingual interface: Kazakh by default, Russian and English, backed by a typed dictionary checked in CI
- Add an ingest queue built for a field day: per-file states, byte-level upload progress, SHA-256 duplicate detection, failures that survive reload
- Add engine caveats and GSD-derived surveyed area to the inspector and reports

### Bug Fixes
- Fix zero counts on high-altitude frames: an unknown scale now tiles at a measured default instead of trusting the whole frame
- Fix the season headline double-counting repeat surveys: the estimate takes the latest sortie per site and names the raw observation total separately
- Fix fabricated figures across the interface: invented coverage percent, density, forecasts, anomaly insights and a hardcoded version badge are gone
- Fix NaN coordinates on geo-less sorties, a fabricated 75 m altitude, camera thrash during loading and the map hiding sorties with unparseable dates
- Fix manual pinning: the pin arms itself when a file needs a location, the upload panel stays within the screen and attention cards scroll into view

### Improvements
- Improve performance: windowed lists render 29 rows instead of 1475, parallel loading paints first content in ~50 ms, colony hulls are cached, verdicts write in batches
- Improve the map: colony outlines with count-band chips, opaque overlays over satellite imagery and an expandable labelled menu
- Improve the dark theme from pitch black to a legible ramp with WCAG-checked contrast
- Improve CI: a platform gate runs type checks, dictionary parity and six selftests, and the version badge must match the release tag
---
### Breaking Changes
⚠️ Full-video consensus analysis is no longer offered by the upload flow — every video is counted through a chosen frame; the service capability remains for other clients
---

## Что изменилось
### Новые возможности
- Добавить выбор кадра для видео: лучший кадр выбирается в большом лайтбоксе и считается как снимок, с честной пометкой basis и предупреждением о движении, если клип летел по маршруту
- Добавить полевые заметки, ручной наземный учёт, имена участков, исправление метаданных и вывод съёмки из оборота с Undo — каждая запись атрибутирована и хранится в журнале правок
- Добавить рабочий цикл проверки в масштабе: вердикты с клавиатуры идут от самых слабых детекций, проход переживает Escape и перезагрузку
- Добавить экспорт GeoJSON/CSV по каждому животному и PDF-акт учёта с казахским и кириллическим текстом
- Добавить динамику участка по повторным визитам и панель доверия: доля проверенного, происхождение масштаба, оговорки движка и детерминизм
- Добавить трёхъязычный интерфейс: казахский по умолчанию, русский и английский, на типизированном словаре с проверкой в CI
- Добавить очередь загрузки для полевого дня: пофайловые статусы, прогресс в байтах, дедупликация по SHA-256, сбои переживают перезагрузку
- Добавить оговорки движка и обследованную площадь из GSD в инспектор и отчёты

### Исправления
- Исправить нулевые подсчёты на кадрах с большой высоты: неизвестный масштаб теперь режется плитками замеренного размера, а не доверяется целому кадру
- Исправить двойной счёт повторных облётов в шапке сезона: оценка берёт последний вылет по каждому участку, а сырое число наблюдений названо отдельно
- Исправить сфабрикованные показатели в интерфейсе: выдуманные процент покрытия, плотность, прогнозы, «аномалии» и захардкоженный бейдж версии удалены
- Исправить NaN-координаты у съёмок без гео, сфабрикованную высоту 75 м, дёргание камеры при загрузке и скрытие съёмок с нечитаемой датой на карте
- Исправить ручной пиннинг: пин взводится сам, когда файлу нужно место, панель загрузки не вылезает за экран, карточки внимания подъезжают в видимую область

### Улучшения
- Улучшить производительность: оконные списки рисуют 29 строк вместо 1475, параллельная загрузка показывает первый контент за ~50 мс, контуры лежбищ кэшируются, вердикты пишутся пачками
- Улучшить карту: контуры лежбищ с чипами диапазонов, непрозрачные оверлеи над спутником и раздвижное меню с подписями
- Улучшить тёмную тему: из смоляной — в читаемую рампу с контрастом, проверенным по WCAG
- Улучшить CI: гейт платформы гоняет проверку типов, паритет словаря и шесть селфтестов, а бейдж версии обязан совпадать с тегом релиза
---
### Ломающие изменения
⚠️ Полный консенсусный анализ видео больше не предлагается при загрузке — каждое видео считается через выбранный кадр; возможность сервиса сохранена для других клиентов
