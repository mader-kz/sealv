## What's Changed
### Bug Fixes
- Fix pollution incidents showing the collector's own English words on a trilingual screen: the placeholder cause "Cause not yet determined.", the location precision `exact` / `approximate` / `field`, the incident kind in the hover tip, and a bare `m` for metres.
- Fix the pollution tooltip overflowing its own box and running off the edge of the map.
- Fix the dialog's screen-reader close label being the one untranslated string left in the interface.
- Fix the environment collector being SIGKILLed on every redeploy: it now stops when asked, in under a second, instead of finishing a cycle that takes minutes.

## Что изменилось
### Исправления
- Исправить показ инцидентов загрязнения словами сборщика по-английски на трёхъязычном экране: заглушку причины «Cause not yet determined.», точность места `exact` / `approximate` / `field`, вид происшествия во всплывающей подсказке и голую `m` вместо метров.
- Исправить всплывающую подсказку загрязнения, вылезавшую за собственную рамку и за край карты.
- Исправить подпись закрытия диалога для экранных читалок — единственную непереведённую строку, остававшуюся в интерфейсе.
- Исправить принудительное убийство сборщика среды при каждом редеплое: теперь он останавливается по просьбе меньше чем за секунду, а не досчитывает цикл длиной в минуты.
