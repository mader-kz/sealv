## What's Changed
### New Features
- Add an upload scanning stage with clearer drop-zone feedback, queue states and translated guidance.
- Add a count replay when opening a site's standing-count photograph.

### Bug Fixes
- Fix map chips overflowing the map edge, show an extent disc for sites without animal locations, and retain usable satellite imagery when detailed tiles are unavailable.

## Что изменилось
### Новые возможности
- Добавить этап сканирования загрузки с более понятной обратной связью в зоне перетаскивания, состояниями очереди и переведёнными подсказками.
- Добавить реплей подсчёта при открытии фотографии с численностью на карточке участка.

### Исправления
- Исправить выход меток карты за её границы, показывать круг охвата для участков без координат животных и сохранять пригодные спутниковые снимки, когда детальные тайлы недоступны.
