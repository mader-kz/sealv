## What's Changed
### New Features
- Add a metric scale bar to the map, drawn in the instrument's own hairline rather than the white-on-white control MapLibre ships.

### Bug Fixes
- Leave pin mode with Escape or a visible Cancel — the mode changed the cursor and reinterpreted every click, and had no exit but a correct answer.
- Close the site card from the keyboard, taking an open replay or an unfinished rename first, so one Escape never discards typing along with the panel.
- Open the map with the crosshair armed when a file needs a location, once per file, instead of asking for a point on a screen that has no map.
- Reach "Withdraw from the count" from the sortie inspector; the only entry point appeared on hover in the archive list and was unreachable from a tablet.

### Improvements
- Draw the hand-placed anchor as a sight, a solid centre inside a ring, so it can be found on an empty coast; it was an 11-pixel dot.
- Dim the chip stalks together with the plates in pin mode instead of leaving them as pale scratches across a faded chart.
- Drop MapLibre's raw zoom number from the coordinate panel and keep the sentence about the precision actually recorded.

## Что изменилось
### Новые возможности
- Добавить на карту метрическую масштабную линейку, отрисованную тонкой линией интерфейса, а не белым по белому, как её отдаёт MapLibre.

### Исправления
- Выходить из режима пина по Escape и по видимой кнопке «Отмена» — режим менял курсор и переопределял каждый клик, а выхода, кроме правильного ответа, не было.
- Закрывать карточку участка с клавиатуры, снимая сначала открытый реплей или незавершённое переименование, чтобы одно нажатие Escape не отбрасывало набранное вместе с панелью.
- Открывать карту со взведённым прицелом, когда файлу нужно место, — один раз на файл, а не спрашивать точку на экране без карты.
- Открывать «Вывести из учёта» из инспектора съёмки: единственная точка входа появлялась по наведению в списке архива и с планшета была недостижима.

### Улучшения
- Рисовать поставленный вручную якорь прицелом — плотный центр в кольце, — чтобы находить его взглядом на пустом побережье; раньше это была точка 11 пикселей.
- Гасить «ножки» чипов вместе с плашками в режиме пина, а не оставлять их светлыми царапинами поверх выцветшей карты.
- Убрать из панели координат сырой номер зума MapLibre, оставив осмысленную строку о точности записи.
