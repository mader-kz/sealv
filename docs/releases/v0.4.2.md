The release that makes deployed maps draw their data. Webpack rewrote
MapLibre's worker URL into the page itself; the worker died silently on the
MIME check, and every GeoJSON layer — flight tracks, colony outlines, animal
dots, the replay's map half — rendered as nothing in every production build.

Релиз, после которого карты в продакшене рисуют свои данные. Webpack
переписывал URL воркера MapLibre в адрес самой страницы; воркер молча
погибал на проверке MIME, и все GeoJSON-слои — треки, контуры лежбищ, точки
животных, карта реплея — не отрисовывались ни в одной продакшен-сборке.

## What's Changed
### Bug Fixes
- Fix every map's GeoJSON layers silently rendering as nothing in deployed builds: MapLibre's worker now loads from a plain staged file (`tools/copy-maplibre-worker.mjs` on every dev/build run) instead of a bundler-mangled URL that served the page's own HTML

### Improvements
- Improve the replay map: the camera fits the colony up to zoom 16 and the dots scale up at close zooms, so a 50-metre haul-out reads as a colony rather than a speck

## Что изменилось
### Исправления
- Исправить молчаливую невидимость всех GeoJSON-слоёв карт в продакшен-сборках: воркер MapLibre теперь загружается из обычного файла (`tools/copy-maplibre-worker.mjs` при каждом dev/build), а не по искажённому бандлером URL, отдававшему HTML самой страницы

### Улучшения
- Улучшить карту реплея: камера приближается к лежбищу до зума 16, точки укрупняются на близких зумах — 50-метровое лежбище читается как колония, а не как точка
