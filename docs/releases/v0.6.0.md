## What's Changed
### New Features
- Add an autonomous six-month Caspian pollution monitor that collects oil and gas incidents from 31 public news, operator, government, NGO, and satellite sources.
- Add pollution incidents, source health, age, uncertainty, and incremental live updates to the unified Caspian map.
- Add timestamped population movement history, regional checkpoints, and a timeline crosshair for reviewing changes at a selected moment.

### Improvements
- Harden pollution polling with isolated process deadlines, bounded responses, host pacing, exponential backoff, partial-result preservation, and durable source cursors.
- Replace coordinate-heavy seal markers with the supplied transparent seal icon and the standing seal count.
- Remove the demo gallery artifacts so the deployed interface contains only operational survey and monitoring views.

## Что изменилось
### Новые возможности
- Добавить автономный монитор загрязнения Каспия за шесть месяцев, который собирает сведения о нефтегазовых инцидентах из 31 открытого новостного, операторского, государственного, общественного и спутникового источника.
- Добавить на единую карту Каспия инциденты загрязнения, состояние источников, давность, неопределённость и инкрементальные обновления в реальном времени.
- Добавить историю перемещений популяций с временными метками, региональные контрольные точки и перекрестие временной шкалы для просмотра изменений на выбранный момент.

### Улучшения
- Повысить надёжность опроса источников загрязнения с помощью изолированных процессов с жёстким лимитом времени, ограничения размера ответов, интервалов между запросами к одному хосту, экспоненциальной задержки, сохранения частичных результатов и устойчивых курсоров источников.
- Заменить перегруженные координатами маркеры тюленей на предоставленную прозрачную иконку тюленя и актуальное количество животных.
- Удалить демонстрационные материалы галереи, чтобы в развёрнутом интерфейсе остались только рабочие представления обследований и мониторинга.
