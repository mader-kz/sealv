First tagged release. The service counts, deploys and is documented. Precision
was verified by rendering every detection over hand-checked ground; **recall is
unmeasured**, because there is no ground-truth count for these frames yet.

That is why this is `0.1.0` and not `1.0.0`. Version `1.0.0` is reserved for the
point where the service has been deployed, has counted a real survey end to end,
and recall has been measured against a hand-counted frame.

Первый релиз с тегом. Сервис считает, разворачивается и задокументирован.
Точность проверена отрисовкой каждой детекции поверх проверенной вручную земли;
**полнота (recall) не измерена** — эталонного подсчёта для этих кадров пока нет.

Поэтому это `0.1.0`, а не `1.0.0`. Версия `1.0.0` зарезервирована за моментом,
когда сервис развёрнут, посчитал реальный облёт от начала до конца, а полнота
измерена на кадре с ручным подсчётом.

## What's Changed
### New Features
- Add CountGD detection for dense aerial imagery — 389 animals on the reference still, whole frame, with no false positives on hand-verified empty ground
- Add counts reported as a `low / best / high` band with its basis recorded, instead of a single integer no one could reproduce
- Add GSD-driven automatic tiling, deriving tile size from altitude and sensor optics rather than a fixed guess
- Add cross-frame temporal consensus with ORB + RANSAC affine registration, so drone drift does not double-count
- Add operator verify mode with an append-only audit log of every added, deleted and confirmed point
- Add georeferencing from DJI SRT and EXIF, producing per-point `lat`/`lng`
- Add GPU inference on Modal with scale-to-zero and weights held in a Volume, measured at 0.87s warm per still
- Add the operator web UI in English, Russian and Kazakh, with locale parity enforced in CI
- Add containerised deployment with a health-checked entrypoint and a required `/data` volume
- Add GitHub Actions CI and a tag-driven Railway release pipeline

## Что изменилось
### Новые возможности
- Добавить детекцию CountGD для плотной аэрофотосъёмки — 389 животных на эталонном кадре целиком, без ложных срабатываний на проверенной вручную пустой земле
- Добавить вывод подсчёта диапазоном `low / best / high` с фиксацией основания вместо одного числа, которое никто не смог бы воспроизвести
- Добавить автоматическое разбиение на тайлы по GSD: размер тайла выводится из высоты и параметров оптики, а не берётся фиксированным
- Добавить межкадровый временной консенсус с аффинной регистрацией ORB + RANSAC, чтобы снос дрона не приводил к двойному счёту
- Добавить режим проверки оператором с append-only журналом каждой добавленной, удалённой и подтверждённой точки
- Добавить геопривязку из DJI SRT и EXIF с координатами `lat`/`lng` для каждой точки
- Добавить GPU-инференс на Modal со scale-to-zero и весами в Volume, замерено 0.87s на кадр в прогретом состоянии
- Добавить веб-интерфейс оператора на английском, русском и казахском с проверкой паритета локалей в CI
- Добавить контейнерный деплой с health-check в entrypoint и обязательным томом `/data`
- Добавить CI на GitHub Actions и релизный пайплайн на Railway по тегу
