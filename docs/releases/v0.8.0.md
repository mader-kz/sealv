## What's Changed
### New Features
- Add a phone layout to the whole interface: the rail becomes a bottom bar, the season summary caps its height and scrolls sideways, review stacks instead of splitting, and the site, pollution and track cards open as full-width sheets.
- Add the sample clip to the build, so "try it without a drone file" works on a deployment and not only on the machine of whoever added it.

### Bug Fixes
- Fix the pollution legend covering the environment panel when both layers are on; every overlay pinned to the map's top-left corner is now a row in one column, measured at 0 px² of overlap across nine viewport widths.
- Fix the missing viewport declaration, without which a phone laid the page out at 980 CSS pixels and scaled it down, leaving every control a third of its intended size and every responsive breakpoint dead.
- Fix two mode headers overflowing the viewport, which widened the layout viewport and dragged the fixed bottom bar out to 590px with its last item off screen.
- Fix touch targets across the app: layer toggles, icon buttons, tabs, the language switcher and the review point rows now reach about 36px on a phone and keep their desktop size above `sm:`.
- Fix the frame picker's remove button being reachable only by hover, which on a touchscreen meant not at all.
- Fix the season summary strip throwing itself back to the previous block when a sideways swipe ended between two of them.

### Improvements
- Improve the bottom bar's active mark to run along its own axis rather than inheriting the vertical rail's left-edge rule, and move each badge onto its icon's shoulder.

## Что изменилось
### Новые возможности
- Добавить мобильную вёрстку всему интерфейсу: рельс становится нижней панелью, сводка сезона ограничена по высоте и листается вбок, «Проверка» стакается вместо разделения на колонки, а карточки участка, загрязнения и трека открываются на всю ширину.
- Добавить в сборку пример ролика, чтобы «попробовать без файла с дрона» работало на развёрнутом приложении, а не только на машине того, кто его добавил.

### Исправления
- Исправить наложение легенды загрязнения на панель среды при двух включённых слоях: все оверлеи левого верхнего угла карты теперь строки одной колонки, наложение 0 px² на девяти ширинах экрана.
- Исправить отсутствие объявления вьюпорта, без которого телефон верстал страницу как 980 CSS-пикселей и ужимал результат, оставляя каждый элемент втрое мельче задуманного, а все адаптивные брейкпоинты — мёртвыми.
- Исправить переполнение вьюпорта в шапках двух режимов, которое расширяло layout viewport и растягивало фиксированную нижнюю панель до 590px с последним пунктом за экраном.
- Исправить размеры целей для пальца: тумблеры слоёв, иконочные кнопки, вкладки, переключатель языка и строки списка проверки достигают примерно 36px на телефоне и сохраняют десктопный размер выше `sm:`.
- Исправить кнопку удаления кадра, доступную только по наведению — на сенсорном экране это означало «недоступна вовсе».
- Исправить полосу сводки сезона, отбрасывавшую себя к предыдущему блоку, когда свайп вбок заканчивался между двумя из них.

### Улучшения
- Улучшить метку активного пункта нижней панели: она идёт по её собственной оси, а не наследует левую черту вертикального рельса, а метки-счётчики переехали на плечо своей иконки.
